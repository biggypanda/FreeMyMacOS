# FreeMyMacOS (macOS temizleyici) v1 — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mac'teki geliştirici, sistem ve tarayıcı çöplerini tarayıp tek tıkla güvenle silen, bellek durumunu gösteren, çok sade ve çok havalı bir native macOS uygulaması.

**Architecture:** Tek bir Swift paketi. `FreeMyMacOSCore` kütüphanesi bütün mantığı taşır (hedef kataloğu, güvenlik bekçisi, tarayıcı, silici, bellek, uygulama durumu) ve AppKit/SwiftUI'ye bağımlı değildir, `swift test` ile test edilir. `FreeMyMacOS` çalıştırılabilir hedefi yalnızca SwiftUI arayüzüdür. `.app` paketi bir script ile derlenip imzalanır; Xcode proje dosyası (`.xcodeproj`) yoktur.

**Tech Stack:** Swift 6 (dil modu 6), SwiftUI, Observation (`@Observable`), Swift Testing (`import Testing`), SwiftPM. Üçüncü parti bağımlılık yok.

**Spec:** Ayrı bir spec dosyası yok; bağlayıcı kararlar bu belgedeki "Tasarım Kararları" ve "Görsel Tasarım Brief'i" bölümleridir.

**"FreeMyMacOS" çalışma adıdır.** Ad ve bundle kimliği yalnızca `Support/Info.plist` ve `Sources/FreeMyMacOS/Theme.swift` içindeki `Brand` sabitinde geçmeli, başka hiçbir yere gömülmemeli.

## Global Constraints

- Proje kökü: deponun kökü (yolda boşluk olabilir, script'lerde her yolu tırnakla). Bu klasör kendi git deposudur, çalışma `v1` dalında yapılır; üst klasör repo değildir, ona dokunma. Hiçbir yere push yapma.
- Dağıtım web sitesinden: **sandbox kapalı**, hardened runtime açık, Developer ID + notarization. Mac App Store hedefi yok.
- Minimum macOS 14.0. `swift-tools-version: 6.0`.
- Arayüz dili v1'de yalnızca İngilizce. Yalnızca koyu tema.
- Silme kalıcıdır (Çöp'e taşımak yer açmaz). Bu yüzden **hiçbir silme `SafetyGuard.validate` çağrılmadan yapılamaz** ve silinebilecek yollar yalnızca `TargetCatalog` içindeki sabit listedir. Kullanıcıdan yol alınmaz.
- Testler asla gerçek ev klasörüne dokunmaz; her test `FileManager.default.temporaryDirectory` altında kendi sahte ev klasörünü kurar.
- Geliştirme makinesi 8 GB RAM: simülatör açma, aynı anda tek derleme çalıştır.
- Uygulama **ücretsiz ve açık kaynaktır (MIT)**. Lisans anahtarı, ödeme, deneme süresi, hesap, telemetri, analitik ve ağ isteği yoktur; uygulama hiçbir sunucuya bağlanmaz. Bunları ekleme.
- Depo herkese açık olacak: koda, testlere, script'lere ve commit'lere kişisel yol (`/Users/<ad>`), e-posta, sertifika adı ya da gizli anahtar yazma. İmzalama kimliği yalnızca ortam değişkeninden gelir.
- Otomatik güncelleme, çoklu dil, açık tema, menü çubuğu modu v1 kapsamı dışıdır. Ekleme.
- Her görev sonunda commit. Commit mesajları `feat:`, `test:`, `chore:` önekli.

## Tasarım Kararları

**Kapsam.** İki özellik: (1) disk temizliği, (2) bellek paneli. Başka özellik yok.

**Temizlik hedefleri.** Hepsi "kök klasörün içindekileri sil, kökü bırak" türündedir. Yollar ev klasörüne görelidir.

| id | Başlık | Grup | Kademe | Kökler |
|---|---|---|---|---|
| `xcode.derivedData` | Xcode DerivedData | developer | safe | `Library/Developer/Xcode/DerivedData` |
| `xcode.simulatorCaches` | Simulator Caches | developer | safe | `Library/Developer/CoreSimulator/Caches` |
| `xcode.deviceSupport` | iOS Device Support | developer | careful | `Library/Developer/Xcode/iOS DeviceSupport` |
| `xcode.archives` | Xcode Archives | developer | careful | `Library/Developer/Xcode/Archives` |
| `swiftpm.cache` | SwiftPM Cache | developer | safe | `Library/Caches/org.swift.swiftpm` |
| `node.cache` | npm / Yarn / pnpm | developer | safe | `.npm/_cacache`, `Library/Caches/Yarn`, `Library/pnpm/store` |
| `python.cache` | pip Cache | developer | safe | `Library/Caches/pip` |
| `cocoapods.cache` | CocoaPods Cache | developer | safe | `Library/Caches/CocoaPods` |
| `gradle.cache` | Gradle Caches | developer | safe | `.gradle/caches` |
| `homebrew.cache` | Homebrew Downloads | developer | safe | `Library/Caches/Homebrew` |
| `browser.caches` | Browser Caches | browsers | safe | `Library/Caches/Google/Chrome`, `Library/Caches/com.apple.Safari`, `Library/Caches/Firefox`, `Library/Caches/company.thebrowser.Browser` |
| `user.caches` | App Caches | system | safe | `Library/Caches` (hariç tutmalarla, aşağıda) |
| `user.logs` | User Logs | system | safe | `Library/Logs` |
| `trash` | Trash | system | careful | `.Trash` |

- `user.caches` şu çocukları atlar: adı `com.apple.` ile başlayanlar, uygulamanın kendi bundle kimliği, ve başka bir hedefin kökü ya da kök atası olan çocuklar (`org.swift.swiftpm`, `Yarn`, `pip`, `CocoaPods`, `Homebrew`, `Google`, `Firefox`, `company.thebrowser.Browser`). Bu liste elle yazılmaz, katalogdan türetilir.
- **safe** kademesi varsayılan olarak seçilidir. **careful** varsayılan olarak seçili değildir ve seçiliyken temizlemeden önce onay penceresi çıkar.
- `.Trash` ve `com.apple.Safari` Tam Disk Erişimi ister. Erişim yoksa hedef `permissionDenied` durumunda görünür, satırda "Grant access" bağlantısı `x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles` adresini açar. Uygulama izin için kendiliğinden pencere açmaz.

**Boyut ölçümü.** `totalFileAllocatedSizeKey` toplamı; sembolik bağlar izlenmez, bağın kendisi sayılır. Gösterim `.byteCount(style: .file)` (Finder ile aynı, ondalık).

**Bellek paneli.** Kullanılan/toplam bellek çubuğu (`host_statistics64`), belleği en çok kullanan 5 uygulama ve her biri için "Quit" (`NSRunningApplication.terminate()`, zorla kapatma yok). "Free RAM" düğmesi `/usr/sbin/purge` komutunu yönetici parolası isteyerek çalıştırır. Ayrıcalıklı yardımcı (helper daemon) kurulmaz.

**Dürüstlük kuralı (anti-goal).** Sahte ya da şişirilmiş sayı gösterilmez, korkutucu uyarı dili kullanılmaz, arka planda sürekli tarama yapılmaz. Gösterilen her bayt ölçülmüş bayttır.

## Görsel Tasarım Brief'i

Hedef his: tek bakışta anlaşılan, sakin, pahalı duran bir araç. Ekranda bir ana sayı, bir ana düğme var; gerisi sessiz.

- **Pencere:** sabit 880×560, başlık çubuğu gizli (`.windowStyle(.hiddenTitleBar)`), yeniden boyutlanmaz, arka plandan sürüklenebilir.
- **Yerleşim:** sol 340 pt "hero" bölgesi, sağda hedef listesi, en altta 56 pt bellek şeridi.
  - Hero: 220 pt halka. Halkanın dolu yayı = seçili temizlenebilir bayt / disk toplamı (en az 4° görünür). Ortada büyük sayı ("31.1"), altında küçük birim ("GB can go"). Halkanın altında tek birincil düğme: `Clean 31.1 GB`. Onun altında ikincil metin düğmesi: `Rescan`.
  - Liste: grup başlıkları (Developer, Browsers, System) küçük, büyük harf, ikincil renk. Her satır: SF Symbol, başlık, sağda tek aralıklı rakamlarla boyut, en sağda yuvarlak seçim işareti. Satır yüksekliği 44 pt. Kutu/kart çerçevesi yok; yalnızca hover'da hafif yüzey.
  - **Açılır detay:** satırın gövdesine tıklamak satırı açar/kapatır, yalnızca yuvarlak işarete tıklamak seçimi değiştirir. Başlığın yanında küçük bir ok (`chevron.right`, açıkken 90° döner). Açılan bölümde sırayla: hedefin `detail` cümlesi (ikincil renk, 12 pt), en büyük 5 öğe (ad tek aralıklı 11 pt, sağda boyut), altta solda "and N more", sağda "Show in Finder" (`NSWorkspace.activateFileViewerSelecting` ile kökleri açar). Aynı anda tek satır açık kalır. Açık satır `surface` arka planı alır. Liste dikey kayar, açılan satır görünür alana kaydırılır. `permissionDenied` satırı açılınca öğe listesi yerine neden izin gerektiğini ve "Open Privacy settings" bağlantısını gösterir. Detay, tarama ve temizlik sırasında da açılabilir.
  - Bellek şeridi: ince çubuk, "11.2 of 16 GB", sağda `Free RAM`. Tıklanınca en çok kullanan 5 uygulamayı gösteren popover.
- **Renk belirteçleri** (`Theme.swift`):
  - `background` `#0B0D12`, üstünde pencere merkezinin sol üstünden yayılan çok hafif radyal aksan parıltısı (opaklık ≤ 0.10)
  - `surface` beyaz %4, `surfaceHover` beyaz %7, `stroke` beyaz %8
  - `textPrimary` beyaz %92, `textSecondary` beyaz %55, `textTertiary` beyaz %32
  - `accentStart` `#5EF2C4`, `accentEnd` `#3AA8FF` (halka ve birincil düğmede doğrusal gradyan; başka yerde kullanma)
  - `warning` `#FFB454` (yalnızca careful kademesi işareti ve izin durumu)
- **Tipografi:** sayılar SF Pro Rounded; hero sayısı 64 pt semibold, `.monospacedDigit()`, `.contentTransition(.numericText())`. Gövde 13 pt, grup başlığı 11 pt medium, harf aralığı +0.6.
- **Köşe:** düğme 14, popover 22. Birincil düğme yüksekliği 48, tam genişlik.
- **Hareket:** tek yay `spring(response: 0.5, dampingFraction: 0.8)`. Tarama sırasında halka yavaşça döner ve satır boyutları geldikçe belirir. Temizlikte sayı sıfıra doğru akar, halka boşalır, bitince ortada onay işareti ve "Freed 31.1 GB" 2 saniye durur. `accessibilityReduceMotion` açıksa dönme ve akma yok, yalnızca geçiş.
- **Yasaklar:** emoji, birden fazla aksan rengi, gölgeli kartlar, yan menü, sekme çubuğu, ayarlar ekranı, ilerleme yüzdesi yazısı.

public enum SafetyError: Error, Equatable { case outsideAllowedRoots, isAllowedRootItself, rootTooShallow }

- Test: `Tests/FreeMyMacOSCoreTests/AppModelTests.swift`, `Tests/FreeMyMacOSCoreTests/MemoryStatsTests.swift`

**Interfaces:**
- Consumes: `Scanning`, `Cleaning`, `CleanTarget`, `ScanResult`, `CleanReport`, `DiskSpace`
- Produces:
```swift
public struct MemoryStats: Sendable, Equatable {
    public let total: Int64
    public let used: Int64             // (active + wired + compressed) sayfa × sayfa boyutu
    public static func current() -> MemoryStats?
}
@MainActor @Observable public final class AppModel {
    public enum Phase: Equatable { case idle, scanning, ready, cleaning, done(freed: Int64) }
    public private(set) var phase: Phase
    public private(set) var results: [String: ScanResult]
    public private(set) var failures: [CleanFailure]
    public var selection: Set<String>
    public let targets: [CleanTarget]
    public init(targets: [CleanTarget], scanner: any Scanning, cleaner: any Cleaning)
    public var visibleTargets: [CleanTarget] { get }   // status != .missing olanlar, katalog sırasıyla
    public var selectedBytes: Int64 { get }            // seçili ve status == .ok olanların toplamı
    public var needsConfirmation: Bool { get }         // seçimde careful kademesi var mı
    public func scan() async
    public func clean() async
}
```
Davranış: `scan()` hedefleri eşzamanlı tarar, sonuçlar geldikçe `results`'a yazar; bitince seçim = `safe` kademesinden `status == .ok` ve `bytes > 0` olanlar; faz `ready`. `clean()` seçili hedefleri sırayla temizler, faz `done(freed:)` olur, ardından temizlenen hedefler yeniden taranır. Faz `scanning` ya da `cleaning` iken gelen `scan()`/`clean()` çağrıları hiçbir şey yapmadan döner.

  - `selectedBytesIgnoresPermissionDenied`
  - `cleanSumsFreedBytesAndCollectsFailures`: iki hedef, raporlar 100 ve 250 → `phase == .done(freed: 350)`, `failures` birleşik
  - `needsConfirmationWhenCarefulSelected`
  - `reentrantScanIgnored`: asılı duran sahte tarayıcıyla iki `scan()` → tarayıcı her hedef için tam bir kez çağrıldı
